~/projects

Projects

Products I've built: the problem behind each one, the stack, and where AI fits in.

PWA · Group game tracker

Chambrage

A progressive web app for groups of friends to log their game nights and rank everyone with Elo-style ratings.

Problem
Game nights end in endless debates about who's actually the best, and scores on paper get lost. Groups need a shared record that ranks players fairly, even when they don't all play the same number of games.
Stack
  • PWA
  • JavaScript
  • Service Worker
  • Elo rating
Where AI could fit in
Log a match in plain language (“Sam beat Lina 3–1 at Catan”), get recaps and rivalry stats generated after each night, and have balanced teams suggested from everyone's rating.

Web app · Auto parts aggregator

PartHub

A web app that aggregates auto parts from several sources, so you can search once and compare everything in one place.

Problem
Finding the right car part means checking several sites, each with its own references, naming and prices. Comparing them by hand is slow, and it's easy to order a part that doesn't fit.
Stack
  • Full-stack web
  • Data aggregation
  • Search & filters
Where AI could fit in
Match equivalent parts across catalogs despite different naming, let users search in plain language (“front brake pads for a 2016 Clio”), and flag likely compatibility issues before checkout.

SaaS · AI code reviewLive

CodeLens

An AI code review SaaS: paste code into a Monaco editor and get a structured review streamed in real time. Deployed on Vercel.

Problem
Getting quick, structured feedback on a piece of code usually means waiting for a teammate, and raw chatbot answers are hard to scan, share or come back to.
Stack
  • Next.js
  • TypeScript
  • Gemini AI
  • Monaco
  • Vercel
Where AI fits in
AI is the core of the product: the Gemini review is streamed live and organised by category and severity, then saved to a persistent history with shareable URLs.
